## Overview

Fluid Must Flow adds large-bore pipe infrastructure (2×2 and 3×3 entity sizes) to Factorio for moving fluids at dramatically higher throughput than vanilla pipes, preventing the fluid throughput bottlenecks that plague large bases. The large pipes have increased segment limits and significantly higher volume-per-tick flow rates.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Fluid Must Flow** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Large-Bore Pipes** | 2×2 and 3×3 oversized pipes for high-volume fluid transport |
| **High Throughput** | Significantly higher fluid volume-per-tick than vanilla pipe segments |
| **Extended Length** | Increased maximum underground pipe distance for factory-crossing runs |
| **Visual Clarity** | Color-coded fluid visualization on large-bore pipe segments |
